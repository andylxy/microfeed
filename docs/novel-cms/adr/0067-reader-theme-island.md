# ADR-0067: 阅读页三态主题岛（白天 / 墨夜 / 暖色）与全站明暗轨道解耦

- 状态：Accepted（2026-11-07 会话设计并实施）
- 日期：2026-11-07
- 关联：ADR-0013（响应式断点）、ADR-0066（前台站点独立模块引擎）、`CONTEXT.md`（「前台主题轨道」节）

## 背景

前台站点（`front-site.css`）的颜色由一组语义令牌（`--mf-*`）驱动，`:root` 与 `.dark` 各定义一份。令牌骨架是健全的，问题在于一批颜色**绕过令牌硬编码**，且存在**两套互不通气的明暗机制**：

- **全站明暗轨道**：`<html class="dark">` 驱动 `.dark` 令牌块，偏好存 `microfeed-public-theme`，覆盖首页/分类页/书页/卷页。
- **阅读页独立夜间**：`<html data-mf-reader-night>` 属性驱动一个只重刷 `.mf-reader-body/header/back/login/chapter-head` 的覆盖块，配一个独立死令牌 `--mf-reader-night-bg`，入口是阅读工具栏一个「◐ 夜间」单按钮 toggle。

结果就是用户看到的「各页颜色深浅不同、乱搭配置」：

1. 阅读/条目页的暖棕 sepia 是**第三种观感**，却既不是全站白天也不是全站墨夜，没有自己的轨道，只能靠一个硬编码覆盖块临时改几条规则。
2. 旧的 `data-mf-reader-night` 块只重刷 `.mf-reader-body/header/back/login/chapter-head` **几个元素**，阅读页里其余部分（`.mf-reader-content`、nav、toc、工具栏）仍吃全站令牌——于是开夜间后阅读页**内部**一半暖灰一半原色。这不是顶栏问题：`.fq-header` 顶栏与站点 footer 在阅读页本就 `display:none`（`html.mf-reader-mode` 块），读者根本看不到它们；真问题是阅读页自身没整页换装。
3. 一次性散值（footer `#19b7fa`、搜索遮罩 `#0f172a73`）与令牌并行，改主题时漏改。
4. 阅读页还有一个旧的「米黄」纸色开关（`html[data-mf-paper=sepia]`），它重定义 `--mf-background/surface/page-bg/text/muted/border` 六个令牌却**不**覆盖 accent/brand/novel——是第二套暖色机制，会盖掉暖色态校准过的链接色。

用户诉求：**白天和黑暗切换要一致，各个页面及颜色值要在同一个体系，不要深浅不同、乱搭配置。**

## 决策

1. **暖棕 sepia 保留为第三主题，但令牌化**——不删这个观感，而是把它提升为阅读页主题岛的三态之一 `warm`，配色全走语义令牌。
2. **阅读页整体（含外壳）自成一套**，新增「暖色」与白天、墨夜并列成三态。
3. **三态覆盖整个阅读页（含外壳，不止旧的几个元素）**——靠在 `<html>` 根层重定义令牌，让阅读页自身外壳与正文整组换装，不再出现「阅读页内一半暖灰一半原色」。`.fq-header` 顶栏与站点 footer 在阅读页本就 `display:none`，用户指定「含顶栏」在现状下自动满足（顶栏不渲染），无需额外处理。
4. **同款下拉菜单 + 独立 localStorage 记忆 + 首次跟随全局**——阅读页用一个三选项下拉（白天/墨夜/暖色）替换旧的「◐ 夜间」单按钮，偏好存独立键 `microfeed-reader-theme`，从未选过则跟随全站偏好起步。
5. **`.fq-*` 顶栏与一次性散值全部令牌化**——顶栏只准吃语义令牌（审计确认它本已如此），散值归并进令牌或按「纯装饰固定色」留注释交代。
6. **移除旧的「米黄」纸色开关**（`html[data-mf-paper=sepia]` 块 + EntryPanel「默认/米黄」按钮组 + `front-site.ts` 的 `data-mf-paper` 逻辑）——它与暖色态值几乎相同、却只覆盖六令牌不动 accent，是会打架的第二套暖色机制。暖色统一由主题岛三态负责。

## 三态令牌组（整组一起换）

三态各自一整组配套色，挂在 `html[data-mf-reader-theme=X]`，切换时整组一起换：

| 令牌 | day（白天） | night（墨夜） | warm（暖色） |
| --- | --- | --- | --- |
| `--mf-background` | `#ffffff` | `#0d1117` | `#f6efe0` |
| `--mf-surface` | `#f6f8fa` | `#161b22` | `#efe4cf` |
| `--mf-text` | `#24292f` | `#f0f3f6` | `#3b3226` |
| `--mf-muted` | `#57606a` | `#9da7b3` | `#6f6350` |
| `--mf-border` | `#dcdcdc` | `#30363d` | `#ddcfb4` |
| `--mf-accent` | `#0997cc` | `#58c7f3` | `#0a7ea4` |
| `--mf-brand` | `#ff4d4f` | `#ff6b6d` | `#c2410c` |
| `--mf-novel` | `#ff6a00` | `#ff8a3d` | `#b45309` |

day 与全站浅色同值、night 与全站深色同值；warm 是阅读页独有的第三态。

**作用域**：三态一律收窄到阅读页，用**服务端渲染时按页面类型定死的静态类** `html.mf-reader-mode`（`FrontLayout` 收到 `isReaderPage` prop 时在 `<html>` 上加；卷页与三个条目页传 `isReaderPage`），配合 `data-mf-reader-theme` 写成 `html.mf-reader-mode[data-mf-reader-theme=X]`。阅读页身份由**页面类型**决定，与 `runtimeHtml`（浮层数据，无标注样式/无实体标记时为 null）解耦——否则这些页会丢主题岛。**刻意避开 `:has(.mf-reader-page)`**：html/body 上的 `:has()` 是相对选择器，阅读页浮层每点一次药材/返回都用 `innerHTML` 重写内容，会触发 html/body 子树整片样式重算，正文越大越卡（实测「点药材、点返回、浮层内交互都很卡」的根因）；静态类只在加载时求值一次，永不随浮层 DOM 变更重算。非阅读页没有 `mf-reader-mode` 类，完全不吃主题岛——否则 day/night 会盖过 `.dark`，把书页/卷页画布钉回白天（「切墨夜后书页背景没完整跟着变」的根因）。阅读页里 `.fq-header` 顶栏与站点 footer 本就 `display:none`（`html.mf-reader-mode` 块），换装只落在阅读页自身外壳与正文上。

**防闪变靠 head 内联播种**：`FrontLayout` 在 `<head>` 里有一段 `is:inline` 脚本，首绘前读 `microfeed-reader-theme`（无则按全站 `microfeed-public-theme` 推 day/night）设好 `data-mf-reader-theme`，避免先按默认白天渲染再跳成墨夜/暖色。`front-site.ts` 里另有一遍兜底播种，脚本晚到时补设。

**字色对比度是按底色逐态校准的**（WCAG 相对亮度，sRGB 线性化）：

- 正文（text 配 background）：三态 10.98–16.99:1，全超 AAA（≥7）。
- muted 配 background：5.13–7.76:1，过 AA（≥4.5）。
- accent/brand/novel 配 background：warm 态原浅色值（`#0997cc`/`#ff4d4f`/`#ff6a00`）在暖底只有 2.5–2.9:1，链接与 hover 字色看不清，换同族深一档（`#0a7ea4`/`#c2410c`/`#b45309`）后回到 ≥4:1。

约束「注意字体颜色要合适」就落在这条：每态字色都配该态底色校过对比度，切态时字色随底色整组换，不会出现暖纸配冷白字这类错配。

## 为何是属性选择器而非 class

阅读页三态挂在 `<html data-mf-reader-theme>` 属性上，属性选择器特异度 (0,1,1) 高于 `.dark` 的 (0,1,0)。这让阅读页**白天态能盖过全站墨夜**——读者在全站开了深色，点进阅读页仍能单独用白天态，不必先把全站切回浅色。出阅读页移除属性即回落全站轨道，两条轨道互不反向牵动。

## 首次跟随全局（单向初值，非双向绑定）

阅读页主题岛的默认取值：读者手动选过则用独立键 `microfeed-reader-theme`；从未选过则读全站键 `microfeed-public-theme`（`dark` ⇒ 起步 `night`，否则 `day`）。这是**单向初值**——阅读页第一次到访贴合读者已有的明暗习惯，但阅读页的后续切换写自己的键，不回写全站偏好。

## 后果

**正向**

- 阅读页不再有绕过令牌的硬编码夜间块与死令牌 `--mf-reader-night-bg`，颜色全部走语义令牌。
- 阅读页自身外壳与正文整组换装，消除「阅读页内一半暖灰一半原色」的内部割裂（旧的 night 块只重刷几个元素）。
- 旧的「米黄」纸色开关退场，暖色只剩主题岛一条轨道，不再打架。
- 三态字色均过对比度校准，暖色态链接色可读。
- head 内联播种让阅读页首绘即命中正确主题，不再闪白天。

**代价 / 取舍**

- 阅读页比全站多一条轨道，改色前须分清一条颜色归哪条管（见 `CONTEXT.md`「前台主题轨道」）。
- 旧的「米黄」纸色开关是一个用户可见控件的移除，会话中已确认（移除纸色开关，暖色统一由主题菜单三态负责）。
- warm 态的 accent/brand/novel 与浅色态不同值（深一档），是为暖底对比度所必须——不是漂移，是有意的同族深档。

## 不做的

- **不改后端 / admin**：本次只动 `front-site.css` / `EntryPanel.astro` / `front-site.ts`，零 DDL、无迁移。
- **不统一两条轨道**：全站明暗与阅读页主题岛刻意保持解耦（阅读页是沉浸阅读场景，值得独立三态），不做「一处切换全站+阅读页联动」的合并。
- **不重写 `.fq-*` 顶栏**：审计确认顶栏本已全令牌化；且它在阅读页 `display:none`，换装落不到它身上，无需为阅读页改它。
