# ADR-0020: 版本门作用域只约束 App 端点

**状态**: 已接受
**日期**: 2026-09-20
**来源**: 提升自 `.scratch/microfeed-rbac/adr/0005-version-gate-scope.md`
**关联**: `0019` `0021` `0022`

## 背景

版本门（最低版本强制）如果作用范围过宽，会误伤 Web 管理后台、OpenAPI 文档等非 App 客户端调用。

## 决策

版本门仅约束 `src/pages/api/AppBookRequest/**/*.ts` 下的 App 业务端点。

## 理由

- 版本协商属于 App 与服务端之间的内部约定，Web 与 API 消费者不参与
- 端点作用域与目录结构一致，代码可读性高

## 后果

- 后端新增 App 端点自动纳入版本门
- 后端新增非 App 端点无需引入版本门，但需自行判断是否纳入
