# ADR-0021: 版本门与数据模型变更的兼容策略

**状态**: 已接受
**日期**: 2026-09-20
**来源**: 提升自 `.scratch/microfeed-rbac/adr/0008-backward-compat-policy.md`
**关联**: `0019` `0020` `0022`

## 决策

### 新增字段

- 后端新增字段，老 App 忽略
- 新增字段必须可选，或有默认值
- 无破坏性

### 删除字段

- 后端不得删除已被 App 使用的字段
- 必须先标记为 deprecated，等下一个大版本再删

### 类型变更

- 禁止。视为新增字段 + 旧字段并存。

### 语义变更

- 禁止直接改。必须新增字段，老字段冻结。

## 后果

- 后端 API 演进路径保守
- 老 App 升级路径平滑
- 后端团队需维护 deprecated 字段清单（无强制工具，人工审查）
