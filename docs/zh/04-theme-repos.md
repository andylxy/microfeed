# 04 主题仓库
> **用途**：处理主题的初始化、导出、复制、fork、检查，或从已保存实例开始开发主题。
> **触发词**：主题初始化、主题导出、主题 fork、主题检查、开发主题、主题仓库、安装主题。
> **加载时机**：命中上述触发词时读取本册；仅做验证，不安装/激活/提交除非另行要求。

- 当用户要求编码智能体初始化、导出、复制、fork、检查或从已保存实例开始开发主题，使用仓库的 `export-microfeed-theme` 技能。
- 用 `yarn manage theme init` 从站点实际外观创建新的主题身份；用户要精确安装不可变版本并保留包身份时用 `yarn manage theme export`。
- 只做初始化/导出与验证。**不要**安装、激活、停用、删除、暂存、提交、建远程或推送，除非用户另行要求。停掉为验证而启动的每个预览服务器。

## 安装主题的 D1 写入规范（每次安装前必做）

- **背景**：D1 单条 SQL 语句的字面量长度上限**实测约 100KB**。**严禁**把 `bundle_json` 等大列用模板插值拼进 SQL 字面量（会超限报错，或被迫分块写入）。
- **安装前的三项确认（每次都做）**：
  1. **写库 SQL 文本里只有 `?` 占位、没有大列字面量**。
  2. **`bundle_json` 与 `preview_fixture_json` 全部经绑定参数传入**（不用字符串拼接 / 模板插值）。
  3. **判据**：整行 `bundle_json` 由一条 `INSERT` 写入，没有出现为绕过 100KB 文本上限而做的分块 `UPDATE`。
- **任一条不满足，先改造通道再执行**：把写入改为「绑定参数 + 单条 INSERT」之后，才允许安装。
