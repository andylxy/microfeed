## 实施计划：管理后台引入 i18n（B2 地基 + 框架性汉化）

### 目标
给管理后台（/admin）引入 i18n 框架（i18next + react-i18next）、套上语言钩子、准备中英文资源，并翻译**框架性组件**（登录/导航/侧边栏/顶栏/设置页/通用控件）。Webhooks/Account/Themes 等大模块留待后续增量批次（符合你认可的增量节奏）。

### 架构决策（依据探索结论）
- 后台是 Astro islands（27 个独立 React 根、无共享 Provider、`AdminPageApp` 仅透传）→ **不逐个包 Provider**，改用 react-i18next 全局实例（`useTranslation()` 无 Provider 时回退全局单例），改动面最小。
- 语言偏好**完全模仿现有主题机制**（`AdminTheme.ts` + `admin-theme.ts` + `AdminThemeScript.astro`）：localStorage + cookie + 内联脚本 + 自定义事件。
- 语言选择 = **浏览器检测（zh 前缀→中文）+ 顶栏手动切换下拉**；切换后写入 localStorage + cookie 并 `location.reload()`，使服务端 `<html lang>`/页面标题与客户端一致。
- 资源放 `src/shared/i18n/`（runtime-neutral，TS 模块而非 JSON，贴合仓库无 JSON 惯例；Astro 服务端可直查表，React 用 useTranslation）。

### 新增文件（10 个）
1. `src/shared/i18n/en.ts`、`src/shared/i18n/zh-CN.ts` — 中英文资源对象（zh-CN 键与 en 严格一致，类型约束）。
2. `src/shared/i18n/index.ts` — `resources`、`supportedLanguages`、`translate(key, lng)` 纯查表函数、`detectLanguage(acceptLanguageHeader)`、类型（`TranslationKey` 从 en 推导）。
3. `src/shared/AdminLanguage.ts` — 模仿 `AdminTheme.ts`：存储 key、语言列表、解析函数。
4. `src/client/admin-language.ts` — 模仿 `admin-theme.ts`：读 localStorage、写 localStorage+cookie、dispatch `microfeed:admin-language-change` 事件、`applyAdminLanguage()` 设 `<html lang>`。
5. `src/client/i18n.ts` — i18next 单例初始化（`initImmediate: false` 同步加载，`lng` 从偏好/检测取，`fallbackLng: "en"`），重导出 `useTranslation`。
6. `src/components/admin/AdminLanguageScript.astro` — 首帧内联脚本设 `<html lang>`，监听 storage/自定义事件/`astro:after-swap`（完全模仿 AdminThemeScript）。
7. `src/components/admin/AdminLanguageMenu.tsx` — 顶栏语言切换下拉（模仿 AdminThemeMenu）。
8. `tests/unit/i18n.test.ts` — 校验 en/zh-CN 键集合一致、translate 行为（属代码行为测试，不违反 AGENTS.md）。

### 修改文件
- `package.json` / `yarn.lock`：`yarn add i18next@^26 react-i18next`（i18next 26.3.6 已在 lockfile，react 18 兼容，无门禁）。
- `src/layouts/AdminShell.astro`、`src/layouts/AdminLoginShell.astro`：`lang="en"` 改为服务端按 cookie/Accept-Language 计算；`<title>` 用 `translate()`；引入 `AdminLanguageScript`。
- `src/pages/[adminPath]/` 下 28 个 .astro：`pageTitle`/`documentTitle`/面包屑改用 `translate()`（大多每处 1-2 个字符串）。
- 框架性 React 组件（约 15 个）：`AdminLoginApp`、`AdminPasswordSetupApp`、`AdminSidebar` + 4 个分区 Sidebar、`AdminUserMenu`、`AdminSearch`、`AdminMobileNavigation`、`AdminThemeMenu`、`AdminHeaderActions`（挂语言菜单）、`SettingsApp`、`AdminSettingsSidebar`、`AdminPageFallback`、`AdminAboutDialog`。
- 通用 shared 控件默认文案（约 8 个）：`AdminDialog`、`AdminInput`、`AdminSelect`、`AdminSwitch`、`AdminTextarea`、`AdminSaveAction`、`AdminHelpLabel`、`AdminCopyableUrl` 等的按钮/占位符/aria 文案。
- 翻译量估计：200–300 条，覆盖登录/导航/侧栏/顶栏/设置框架/通用控件。

### 本次明确不做（留后续批次）
- 服务端错误消息（`jsonResponse({error})` → toast，属 API 契约，改动影响面大）。
- `humanizeMs` 日期本地化（en-US 硬编码，影响公开 feed 输出，需谨慎独立做）。
- Webhooks/Account/Themes/SiteFiles/PageEditor/Items 大模块全文（后续逐个增量）。

### 验证
- `yarn typecheck`（新增 TS 资源类型约束）。
- `yarn test`（含新增 i18n 一致性测试）。
- `yarn build` + `yarn manage deploy` 到现有实例后，登录后台切换中文、检查框架组件中文渲染。
- 结束时停止所有开发/预览服务器，按 AGENTS.md 跑 `git diff --check`，提交到 `chore/admin-i18n` 分支。
