# 03 — 按权限加载菜单

**What to build:** 服务端按当前登录者的权限集算出他能看到的菜单。取菜单表里显示中的行，逐条判定——没绑权限码的是公共项（人人可见），绑了的要看权限集里有没有（超管通配、老版管理员账号、命中该码任一成立即可），然后排序、按父级组装、**剪掉子项全被过滤掉的节点**，最后兜底：一条都不剩时只返回首页，侧栏永不为空。判定必须与现有的权限守卫同源，否则会出现"菜单看不见、直接访问网址却能进"。
