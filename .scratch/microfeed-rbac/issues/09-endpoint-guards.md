# 09 — 端点守卫补齐

**What to build:** 把这些数据端点的权限判定补上——它们目前**只有身份门**（中间件保证已登录），没有权限门，也就是任何登录账号都能直接调。菜单与页面已经收紧了，接口还敞着，等于"门锁了但窗没关"。

**Blocked by:** 01、02

**Status:** done

- [ ] 无权限判定的 `/ajax/**` 端点逐个补上 `requireRbac`，用的码与它所属页面/菜单一致：
      内容项（列表/详情/写入）、页面（含排序）、站点文件（含发布/重置/预览）、审核（含纠错）、
      审计、主题（草稿、预览）、API 密钥、R2 存储操作、volumes 列表
- [ ] 只读端点（列表/详情）用对应的 read 类码，写端点用 write/update 类码
- [ ] 有意不加码的保持不加：账户自助区、登录与凭证登录、搜索建议
- [ ] 新增/扩展测试覆盖至少一个此前无守卫的写端点被拒的场景
- [ ] 门禁全绿
