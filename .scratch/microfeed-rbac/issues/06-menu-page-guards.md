# 06 — 菜单页面的守卫与一致性

> **本票已按票面口径切开（2026-09-23）**：原票含"页面 + 端点"两半。页面这半已交付，**端点那半移到票据 09**
> ——它是一批独立的无守卫端点（内容项 / 页面 / 站点文件 / 审核 / 审计 / 主题 / API 密钥 / 存储操作），
> 与页面守卫不是同一件事，混在一票里既做不完也说不清。

**What to build:** 让"菜单看得见"与"页面进得去"用同一把尺子。除首页外，每个菜单对应的页面都加上权限守卫，且**守卫用的权限码必须与菜单行绑定的那个完全一致**——否则会出现"看得见却 403"。新增一条测试把这条一致性钉住（双向：菜单页必须用绑定的码；任何受守卫页面不得使用没有菜单绑定的码）。
