# 07 — 无权限页面改造

**What to build:** 被权限挡住时给用户一个能用的页面。现在的表现是一屏白底纯文字的 403（没有外壳、没有导航、没有出口），从书签直达的用户会卡在那里。改成一个带外壳的"无权限"页：说明原因，并给一个返回后台的入口。所有有守卫的页面统一用它。

**Blocked by:** 06

**Status:** done

**实现说明**：`requirePagePermission` 在权限不足时**重定向**到 `[adminPath]/forbidden/`，该页在 `AdminShell` 内渲染
提示与"返回首页"入口，并在 frontmatter 里把状态码设为 **403**（因此用户看到的最终响应仍是 403）。
非 403 的拒绝（未登录 / 封禁 / 设备吊销 / 待改密）保持各自状态码原样返回，不当作"你没有这个页面的权限"。

- [ ] 带后台外壳，保留侧栏与顶栏，不出现白屏裸文字
- [ ] 提示文案与返回后台入口齐备（中英文）
- [ ] 所有被守卫拒绝的页面都走这个页面（含 06 新增的守卫点）
- [ ] 状态码仍是 403，不改变既有语义
