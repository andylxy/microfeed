# 06 — 转译脚本：源 SQL → 目标行

**What to build:** 一个可重跑的离线脚本，把源库 8 个表的 MySQL 导出翻译成目标模型的行。它不写生产库，只产出可分批次执行的 SQL 文件，先在人眼前验完再上手。

这是唯一一处"数据正确性"全靠它的地方，所以三条硬性要求：**行数与关联一个不漏**、正文里的标记一个字符不改、转义还原后不含字面 `\n`。
