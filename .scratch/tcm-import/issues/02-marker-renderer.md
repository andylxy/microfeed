# 02 — `$X{}` 标记渲染器（纯函数）

**What to build:** 一个不依赖数据库、不依赖 Worker 运行时的纯函数：把带标记的中医正文渲染成带样式与链接的 HTML。给一段 `"$u{桂枝}$w{三两。去皮}"` 和一个样式清单，还回 `<span>` 包好的 HTML。它是整个迁移里唯一一处"读者能看见的差异"，所以单独成单、先用单测锁死行为。

必须比原 App 做得更对（原 App 的正则不支持嵌套，会把 `$a{$q{《千金》}` 渲染成字面文本还吃掉一个 `}`）。

**Blocked by:** None — can start immediately

**Status:** done（2026-09-28，分支 `feature/tcm-import`；链接目标经 `resolveHref` 注入，公开接线在工单 04）
