# ADR-03 — 标记协议（13 枚语义与配色、linkType 即跳转、两个坑）

- 状态：已采纳（2026-09-28）
- 关联：spec.md §4.2 / §7 / §12；migration 0071；issues 04
- 上游：Android `TipsTextRenderConfig` 渲染配置

## 背景（Context）

正文里嵌 `$X{...}` 标记（如 `$u{桂枝}` 表示中药、`$f{麻黄汤}` 表示方剂），App 端按标记 code
查样式目录自行着色并支持点击跳转。旧后端把 13 枚标记的语义、颜色、字号、跳转类型硬编码在
App 配置里；迁移须把这套协议落到 `ext_annotation_markers` 并让后端能下发。

## 决策（Decision）

`ext_annotation_markers` 加三列：`color TEXT`、`small_font INTEGER`、`link_type INTEGER`
（迁移 0071）。13 枚目录如下（code / 标题 / 颜色 / 小字 0.7em / 跳转类型）：

| code | 标题 | color | small | link |
|---|---|---|---|---|
| f | 方剂 | #0000FF | 否 | 2（方剂） |
| u | 中药 | #0000FF | 否 | 1（中药） |
| a | 按语 | #808080 | 是 | 0 |
| w | 剂量 | #1CB55C | 是 | 0 |
| q | 出处 | #3DC878 | 否 | 0 |
| m | 强调 | #FF0000 | 否 | 0 |
| n | 蓝字 | #0000FF | 否 | 0 |
| g | 名词解释 | rgba(0,128,255,0.90) | 否 | 3（名词） |
| r | 批注 | #FF0000 | 是 | 0 |
| v | 蓝字 | #0000FF | 否 | 0 |
| y | 棕字 | #9A764F | 否 | 0 |
| h | 黑字 | #000000 | 否 | 0 |
| x | 橙字 | #EA8E3B | 否 | 0 |

- **linkType**：1=中药、2=方剂、3=名词；其余 0（纯样式，不跳转）。跳转落地页由对应实体条目页承担。
- **颜色**为 CSS 就绪串（`#RRGGBB` / `rgba(...)`）；`small_font` 映射 `font-size:0.7em`。
- 其中 `$a`/`$u`/`$x` 三枚在 0068 种子时语义写错（按语小字、中药蓝色、橙字），迁移 0071 修正。

## 两个坑（实现时必须容错）

1. **嵌套标记**：标记内容里可能再含标记（如 `$m{见$f{桂枝}}`）。解析须递归，不能一层正则了事。
2. **脏括号**：源数据存在未配对的 `{` / `}`，解析须容错，不能因一处脏数据整段崩。
