### signature / signatureId 机制实锤（用户追问"netcore 数据变动→签名改变"）
- 反解 golden wire：section & fang 的 `signature` = **MD5(UTF8(text))** 32 位大写十六进制；逐字节验证 **315/315 方剂 + 全部条文 MATCH**。源库 `BookBody.Signature / Fang.Signature / FangBody.Signature` 列即此值，netcore 每次新增/修改重算 → 故"数据变动签名就变"。
- `signatureId` = 源库 `SignatureId` 列（源 long 主键）；本项目按拍板用 11 位 id 占位（App 端 long→String）。
