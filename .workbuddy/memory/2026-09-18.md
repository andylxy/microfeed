## 部署到 CF Worker —— 沙箱内为何做不了（精确根因）
- 不是 yarn 的锅：manage CLI 的 runWrangler/runYarnScript 用 packageBinaryJavaScript() 解析 node_modules 里的 JS 再 process.execPath 直跑，绕开坏掉的全局 yarn shim，所以 manage CLI 内部其实能用 yarn（@yarnpkg/cli-dist 已装）。
- 真正卡点：deploy 内置门 runChecks 跑 types -> typecheck -> test:deploy -> build，其中 test:deploy=vitest，本沙箱报 TypeError: Cannot read properties of undefined (reading 'config')；--pool=forks 同样失败 => 环境问题非池类型；无任何 skip-checks 标志。
- 危险点（禁止沙箱跑 deploy）：deployConfiguredProject 中 applyMigrations(远端 D1) 在 runChecks 之前 => 沙箱跑会先动生产 D1 再在测试门 abort，留半成品状态。
- wrangler 登录已存在 C:/Users/zhs/AppData/Roaming/xdg.config/.wrangler/config/default.toml（wrangler 认 %APPDATA%/xdg.config/.wrangler；Bash 需显式 export APPDATA 才可见）。active 实例 ctwh-881019-xyz。
- 结论：deploy 交用户终端 yarn manage deploy；沙箱可预验 = tsc(0) / i18n:check(1686/1686) / theme:release-check(过)。
